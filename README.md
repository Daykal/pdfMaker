This project generates a PDF from a JSON motif file. The PDF includes:

Logo and title

Motif details such as name, width, height, colors, and number of rows to knit

An image showing how the motif should look

Calculations for how and where each “pixel” of the motif should be placed

The code takes care of laying out the motif accurately, so you can see exactly how it will look when knitted. Check the example folder for sample generated PDFs.
